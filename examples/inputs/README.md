# Input templates

These small examples illustrate schemas, not paper samples. Replace identifiers and paths with your data.

- `sites.csv`: one image site with five channels and illumination arrays. Paths are relative to this CSV unless absolute; image files are not included.
- `conditions.csv`: one row per condition, mapping a retrieval record ID to a crop label.
- `crop_labels.csv`: explicit zero-based HDF5 crop row to label mapping for collections without embedded labels. Include every crop row exactly once.
- `identity_crop_ids.csv`: one row per input feature vector, in feature-array order. Each row carries a drug ID, a nonnegative integer drug label and its original crop row. Use the same crop rows and labels across methods for matched identity comparisons.

The four-row crop examples describe two drugs with two crops each. They illustrate table layout; they are not crops generated by the single illustrative site in `sites.csv`. Use globally unambiguous record IDs when combining collections. Original crop rows are unique within one collection.
