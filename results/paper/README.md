# Current paper tables

The lowercase CSV files contain the current named-method results, including CLOOME and CellCLIP. `fig2_identity.csv` summarizes identity retrieval; `fig2_moa.csv`, `fig3_retrieval.csv`, `fig4_retrieval.csv` and `fig5_retrieval.csv` summarize their respective retrieval settings. `fig3_mixing.csv` records the displayed mixing scores.

`fig2_wilcoxon.csv`, `fig3_wilcoxon.csv` and `fig4_wilcoxon.csv` contain paired-query tests and adjusted probabilities. Families and the handling of ties/zero differences are implemented in `reproduce/scripts/wilcoxon_statistics.py`.

Figure 4 tables retain both projection heads; use the MOA-head rows for the displayed main retrieval comparisons. Figure 3 mixing values have a selected-draw convention. Do not interpret all table errors as between-training variation. See [protocol notes](../../docs/REPRODUCTION.md) and `configs/paper.json` for panel-specific assignments.

Regenerate numerical checks with `python reproduce/run.py statistics`. Full composed figures are generated by `python reproduce/run.py figures`; simple table plots are separate conveniences.
